# Habit Tracker App

Fully offline iOS habit tracker (MVP + Phase 2). Planning docs are in [`plan/`](plan/). The SwiftUI app is in [`HabitTracker/`](HabitTracker/).

## Quick start

1. Install **Xcode** from the Mac App Store (required to build/run).
2. Open [`HabitTracker/HabitTracker.xcodeproj`](HabitTracker/HabitTracker.xcodeproj).
3. Set Signing Team on **HabitTracker** and **HabitTrackerWidget** if prompted.
4. Run on an iOS 17+ simulator.

See [`HabitTracker/README.md`](HabitTracker/README.md) for the full feature list. Apple Watch is still deferred.
