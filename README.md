# Habit Tracker App

Fully offline iOS habit tracker. **Canonical workspace:** `/Users/pravar/Apps/HabitTrackerApp` (GitHub: [PravarChaurasia/HabitTrackerApp](https://github.com/PravarChaurasia/HabitTrackerApp)).

Planning docs are in [`plan/`](plan/). The SwiftUI app is in [`HabitTracker/`](HabitTracker/).

## Quick start

1. In Cursor, **File → Open Folder** → `/Users/pravar/Apps/HabitTrackerApp` (this is the mapped repo).
2. Install **Xcode** from the Mac App Store (required to build/run).
3. Open [`HabitTracker/HabitTracker.xcodeproj`](HabitTracker/HabitTracker.xcodeproj).
4. Set Signing Team on **HabitTracker** and **HabitTrackerWidget** if prompted.
5. Run on an iOS 17+ simulator.

See [`HabitTracker/README.md`](HabitTracker/README.md) for the full feature list. Apple Watch is still deferred.
